## Governance

The Aspen Library Software Foundation was set up in 2025 to act as a governing body for the Aspen Library Software project.  The project is governed by a board of directors that is working to make the Aspen Library Software Foundation a part of the nonprofit <a href="https://openlibraryfoundation.org/" target="blank">Open Library Foundation</a>.

## Governing board

The Aspen Library Software Foundation is governed by a board elected annually by members of the Aspen Library Software community.
